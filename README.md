**ПР7. Ответы на контрольные вопросы**

1. Обычный параметр — метод получает копию. Число скопировалось — оригинал не меняется. Объект скопировался — копия ссылки, поля менять можно, а заменить сам объект — нельзя
2. ref — переменная должна быть уже с значением до вызова. out — может быть пустой, но метод обязан туда что-то записать
3. TryParse использует out — потому что старое значение переменной не важно, метод сам кладёт туда результат
4. in — передаёт по ссылке, но менять запрещено. Нужен, чтобы не копировать большие структуры
5. Необязательные параметры — пишутся после обязательных
6. Именованные аргументы — можно не писать ненужные необязательные параметры и менять их порядок
